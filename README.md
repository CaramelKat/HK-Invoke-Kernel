# Harman Kardon Invoke Linux Kernel

This repo serves as a mirror of the HK Invoke kernel, which can be found archived [here](https://archive.org/details/invoke-kernel)

### Upstream Comparison

The contents of this kernel have been placed on top of the 3.8 kernel release. It was the closest I could find to a public commit, so hopefully this can give some better insight into what actually changed in this kernel.
